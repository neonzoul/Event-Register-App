One Thing to Know

The .env File

Every web app has a file that holds its secret keys.
It's called .env — never share it, never push it to GitHub.

# .env — secret keys live here

DATABASE_URL = your-database-key
EMAIL_KEY = your-email-service-key
EVENT_NAME = "Your Conference 2026"

# These go into Vercel → Settings → Environment Variables

When you need to set this up yourself — ask AI:
"How do I add environment variables in Vercel?"

Before You Ship

Real Users Find Real Bugs

⚠ This is normal. Even professional teams ship bugs.

What matters is knowing what to do:
→ Test with 5–10 real people before your event
→ When a bug appears, copy the error → ask AI to fix it
→ Bugs are fixable — not the end of the world

"Live" doesn't mean "perfect." It means "working and improvable."

The One Rule

Specific Beats Vague

❌ VAGUE
"Make it look better"

AI guesses. You get
something random.
✅ SPECIFIC
"Change the button color
to dark green #065f46,
keep the white text"

AI does it exactly.

Like ordering coffee — "coffee" vs "iced latte, oat milk, no sugar."
The more specific, the faster you get what you want.

Don't Panic

When Something Breaks

TypeError: Cannot read properties of undefined
at app/page.tsx:42

← This is good. It tells you exactly what's wrong.

Copy the entire error message.
Paste it to AI. Say: "I got this error — please fix it."

Don't summarize. Don't rephrase. Give AI the raw error.

95% of errors — AI fixes in one go.
